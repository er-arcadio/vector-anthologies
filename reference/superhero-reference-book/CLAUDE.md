# CLAUDE.md — reference/superhero-reference-book/

Seven heroes in development, each with a `status` in the roster snapshot. Start with `roster-overview.md` (criteria + status table) before reading an individual character file.

`power-convergence-guide.md` is a general-purpose calibration reference — useful for any power in either roster, including Vector's, not just this one. Consult it when a story needs to establish how far a given power *could* go without breaking believability.

`06-blink.md` — this hero is unrelated to the Vector villain formerly called "Blink," now renamed `Twitch` (`../../story-bible/villains/twitch.md`). Don't conflate the two.
