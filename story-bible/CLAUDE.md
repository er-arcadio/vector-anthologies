# CLAUDE.md — story-bible/

This is canon reference for the Vector series, not prose. Never draft story text here — prose goes in `../stories/`.

## Reading order for a new task

- **Writing/editing a scene or story?** Start with `../writing-guide/`, then come back here for the specifics you need.
- **Need a character?** → `characters/` (protagonist-side) or `villains/` (antagonist roster).
- **Need power/ability rules?** → `power-system/`.
- **Need what happens in a given arc?** → `plot-outline/arc-0N.md`. For the want/obstacle/resolution shape of Arcs 1–7 specifically, start with `plot-outline/era-1-overview.md` (currently draft, pending author agreement).
- **Checking whether something's already seeded or spoiled?** → `foreshadowing-map.md` and `plot-twist-inventory.md` — always check both before introducing a new reveal.
- **Not sure if something's settled?** → `open-questions.md` for original unresolved items, `action-items-v5.1.md` for the current active development queue (check this one first — it's more current).
