# CLAUDE.md — story-bible/power-system/

- `power-progression.md` — the core knowledge-dependency rule (never breaks — see `../../writing-guide/story-laws.md`) and the Think/Know/Feel-Become three-stage model.
- `arc-by-arc-power-progression.md` — which abilities are at which stage, by arc. Check this before writing a scene set in a specific arc so you don't grant Eli a capability he hasn't earned yet.
- `onset-timeline.md` — when each affected person's power first arrived, and the rule behind it (latency scales with the power's *ceiling*, not its magnitude). Check this before writing any scene that implies someone did or didn't have their power yet. Note that onset is not the same as first public appearance.
- `physical-consequences-and-canon.md` — costs of overuse, and the scientific grounding for his ceiling abilities (subatomic deconstruction, field sensing).
- `abilities-environmental-effects.md` — every ability's real-world physical consequence. Any fight scene should be checked against this table — nothing is silent or clean.
