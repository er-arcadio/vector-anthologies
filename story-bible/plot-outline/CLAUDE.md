# CLAUDE.md — story-bible/plot-outline/

One file per arc (`opening.md`, `arc-01.md` … `arc-09.md`). This is the beat-level outline, not prose — actual scenes go in `../../stories/`.

`era-1-overview.md` is a synthesis layer on top of `arc-01.md`–`arc-07.md`: for each arc (and, where relevant, Vinny's and Iris's parallel tracks), it states the starting point, the want and obstacle, and the resolution and its cost. **Currently a draft pending author agreement** — read its "Open Gaps Needing a Decision" section before assuming any of it is settled. Start here when outlining an Era 1 short story instead of re-deriving want/obstacle/resolution from the raw arc file alone.

`arc-08.md` (the alternate-planet arc) is flagged as least developed — see `../action-items-v5.1.md` item 3 before writing anything set there, since its world logic isn't finalized.
