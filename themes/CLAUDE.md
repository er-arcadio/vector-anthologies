# CLAUDE.md — themes/

Thematic source material — lessons/philosophy that might surface across the anthology (Vector, the reference roster, or both). Not prose, not canon, not a craft tool. Where and how any of this actually shows up in a story isn't decided yet — it could be ambient (baked into how the world works, how characters already act) or explicit (a character's stated journey/lesson). Treat that as an open creative decision per-story, not something to force.

- `lessons-for-young-men.md` — general-audience life lessons (middle school through college).
- `lessons-for-young-men-adult.md` — same source, but the college-and-up material intended for an 18+ audience (physical/romantic escalation, etc.). Flagged `content_rating: adult` in frontmatter. If any of this surfaces in a story, it's still bound by `writing-guide/story-laws.md` and `writing-guide/style-guide.md` — adult content is permitted where it serves character arc, never as decoration.

**Not here:** the in-world moral/spiritual framework referenced in Vector's own setting (see `story-bible/moral-framework.md`) is a related but separate thing — that's Vector canon describing a fictional religion inside the story world. The full standalone framework it's loosely evocative of (its complete text, name, rites, and any real-world publishing plan) is being developed in a different repo entirely and is out of scope here. Don't import that project's specific text/branding into this repo.
