## Goal
`build_site.py` publishes every file under `stories/` regardless of `canon_status` or `eval_status`, and sorts only by the date written, newest first. So a flagged draft goes public automatically and reading order cannot be controlled.

## Inputs
`scripts/build_site.py`, `stories/CLAUDE.md`.

## Outputs
A change to `build_site.py` adding status filtering and an ordering override, with the convention documented in `stories/CLAUDE.md`.

## Definition of done
- [ ] Drafts and flagged stories can be excluded by configuration, not by moving files
- [ ] Reading order controllable independently of the written date
- [ ] Existing published stories are unaffected unless deliberately excluded
- [ ] The build still succeeds with no stories present
