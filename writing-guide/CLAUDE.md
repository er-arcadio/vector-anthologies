# CLAUDE.md — writing-guide/

Six files, covering three stages of making a story. Read `style-guide.md` and `story-laws.md` before drafting prose; read `outline-checklist.md` and `character-journey-worksheet.md` before sequencing a new arc or story, ahead of drafting; run `eval-checklist.md` against a finished draft before filing it as done.

**Drafting prose (scene-level):**
- `style-guide.md` — tone, voice, prose technique, and the short-story length target (1,500–4,000 words). Preferences, but firm ones. This is the drafting-ready version to follow — it already incorporates the sustained-dialogue and mostly-present-tense defaults from `fiction-style-profile.md`.
- `story-laws.md` — hard canon constraints. Not preferences. If a story idea conflicts with one of these, flag it rather than resolve it silently.
- `fiction-style-profile.md` — the reader-preference research (real books ranked against each other) that `style-guide.md`'s prose defaults were derived from — still real preference rules, just not yet in imperative, drafting-ready form. If it and `style-guide.md` ever seem to disagree, that means the profile hasn't been fully folded in yet — fix `style-guide.md` rather than splitting the difference while drafting.

**Outlining (before any scene is written):**
- `outline-checklist.md` — a checklist for the "this happened, then this happened" stage: causality, obstacle variety, escalation, choice points, twist planting, and outline-readiness checks. Run through it while sequencing events for a new arc or story, before drafting.
- `character-journey-worksheet.md` — a template, filled out once per POV/major character before outlining. Referenced from `outline-checklist.md` (its Section 0) and checked against individual beats throughout.

**Evaluating a finished draft:**
- `eval-checklist.md` — the quality gate for prose that's already written: length, style-guide compliance, story-laws compliance, and a cross-check against `story-bible/foreshadowing-map.md` and `story-bible/plot-twist-inventory.md`. Run once per draft; record the result in the story's own `eval_status` frontmatter (see `../stories/CLAUDE.md`).

If any of these files needs to change because canon or preference has evolved, update it directly — but treat that as a deliberate decision, not an incidental edit while drafting a story.
