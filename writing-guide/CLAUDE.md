# CLAUDE.md — writing-guide/

Two files, both mandatory reading before drafting anything in `stories/`:

- `style-guide.md` — tone, voice, prose technique. Preferences, but firm ones.
- `story-laws.md` — hard canon constraints. Not preferences. If a story idea conflicts with one of these, flag it rather than resolve it silently.

If either file needs to change because canon has evolved, update it directly — but treat that as a deliberate decision, not an incidental edit while drafting a story.
