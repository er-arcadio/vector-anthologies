# CLAUDE.md — writing-guide/

Three files. Read `style-guide.md` and `story-laws.md` before drafting anything in `stories/`; `fiction-style-profile.md` is supporting material, not a third rulebook.

- `style-guide.md` — tone, voice, prose technique. Preferences, but firm ones. This is the canonical, resolved version to follow — it already incorporates the sustained-dialogue and mostly-present-tense defaults from `fiction-style-profile.md`.
- `story-laws.md` — hard canon constraints. Not preferences. If a story idea conflicts with one of these, flag it rather than resolve it silently.
- `fiction-style-profile.md` — the reader-preference research (real books ranked against each other) that `style-guide.md`'s prose defaults were derived from. Read it if you want the reasoning behind a rule or want to extend it with a new comparison; don't treat it as a second, independent source of instructions. If it and `style-guide.md` ever seem to disagree, `style-guide.md` wins — that means the profile hasn't been folded in yet, and the fix is to update `style-guide.md`, not to split the difference while drafting.

If any of these files needs to change because canon or preference has evolved, update it directly — but treat that as a deliberate decision, not an incidental edit while drafting a story.
